# Tirupati Spice House 🍛

A beautiful restaurant website built using Vibe Coding with Bolt.

**Live Demo:** https://tirupati-spice-house-nq3x.bolt.host

## What I Built
- Hero section with "Authentic Rayalaseema Taste"
- Menu with 8 dishes - Biryani, Dosa, Meals, Chicken Curry
- Add to Cart with total calculation
- About Us, Location & Timings
- Book a Table & WhatsApp button

## Built With
- React + Vite + Tailwind CSS
- Bolt.new (AI Vibe Coding)

## How to Run
1. Clone this repo
2. Run `npm install`
3. Run `npm run dev`
